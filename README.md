### sun

The sun uses a 3D sphere model created with the program on [3DModelEditor](https://github.com/taKana671/3DModelEditor).<br>
Applied two noise textures to the model and offset them over time.
Also placed a large, flat 3D plane model at the center of the sun, facing the camera, and applied a shader to that plane model to simulate solar flares.

### rogue planet

The rogue planet was created using 3D models generated by performing a Voronoi tessellation on a sphere using the program on the [voronoi_generator](https://github.com/taKana671/voronoi_generator.git).
It appears every 20 seconds, explodes with a flash of light, and sends debris flying in all directions.<br>
The flash is rendered using TextureAtlas, and the positions of the scattered 3D models are calculated using curl noise.

### green

A Planet Teeming with Greenery.


### snow

A planet that is always covered in snow.<br>
Parent a 3D model of a transparent sphere—slightly larger—to the planet, and by applying a shader to that larger 3D model to create the appearance of white clouds over the planet.


### earth

An earth-like planet.


### desert

A planet made of sand and rock.<br>
It orbits, with rock fragments trailing behind and ahead of it.<br>
The fragments, like the rogue planet, were created by performing a Voronoi tessellation on a sphere.


### ice

A planet made of ice.<br>
The planet's rings were created by arranging particles generated from panda3D's GeomPoints in concentric circles using the programs on [shapes](https://github.com/taKana671/shapes.git).


### sakura

A planet whose landmass is covered in cherry blossoms.<br>
It has a comet-like tail.<br>
The comet's tail is rendered using panda3D's MotionTrail.

# Usage

### Clone this repository.

```
git clone --recursive https://github.com/taKana671/VirtualPlanets.git
```

### Build cython code.

```
cd VirtualPlanets
python setup.py build_ext --inplace
```

If the error like "ModuleNotFoundError: No module named ‘distutils’" occurs, install the setuptools.

```
pip install setuptools
```

### Run fluid_cube.py

```
python virtual_planets.py
```

Drag the mouse to change the camera's orientation.
